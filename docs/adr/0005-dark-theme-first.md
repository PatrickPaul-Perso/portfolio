# ADR 0005: Use a dark theme first

## Context

The desired visual identity uses dark surfaces and multiple blue accents while remaining accessible and professional.

## Decision

Use a dark theme as the initial design system, with high-contrast text, visible focus states, and restrained decorative effects.

## Consequences

Contrast must be tested carefully. Decorative network and 3D-printing references must remain subtle and must not reduce readability.

## Alternatives considered

- Light theme first: does not match the selected visual direction.
- User-selectable themes in the first milestone: deferred to avoid unnecessary complexity.
