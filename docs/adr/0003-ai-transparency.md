# ADR 0003: Disclose generative AI assistance

## Context

Generative AI assists with writing, design exploration, documentation, translation, and software development in this project.

## Decision

Provide a visible footer notice, a public transparency page, and repository documentation describing AI use and human accountability.

## Consequences

Visitors and reviewers can understand how AI contributed. Patrick Paul remains responsible for factual validation, technical decisions, code review, and publication approval.

## Alternatives considered

- No disclosure: rejected because it does not meet the project's transparency standard.
- A footer notice only: rejected because it lacks sufficient context.
