# Accessibility

The portfolio targets WCAG 2.2 AA.

## Baseline requirements

- Semantic landmarks and heading hierarchy
- Full keyboard access
- Visible focus indicators
- Sufficient colour contrast
- Reduced-motion support
- Responsive layouts at narrow widths and high zoom
- Meaningful alternative text for informative images
- No information conveyed by colour alone

Accessibility checks should accompany any change to navigation, interactive controls, typography, animation, colour, or media.
