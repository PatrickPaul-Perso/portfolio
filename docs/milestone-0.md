# Milestone 0: Repository Foundation

## Scope

- Static Astro project foundation
- GitHub Pages deployment workflow
- Bilingual routes and initial language routing
- Accessible dark theme foundation
- Generative AI transparency
- Engineering, architecture, accessibility, localization, and contribution documentation

## Exit criteria

- The branch can be installed and built successfully.
- The English and French pages render under the GitHub Pages base path.
- The deployment workflow publishes `dist` after merge to `main`.
- The repository documents how AI was used and who remains accountable.
