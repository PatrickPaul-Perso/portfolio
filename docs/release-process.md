# Release Process

1. Complete a focused milestone branch.
2. Confirm documentation and implementation agree.
3. Run validation checks locally.
4. Open a pull request against `main`.
5. Review the file changes and workflow result.
6. Merge only when the branch is buildable and coherent.
7. Confirm the GitHub Pages and Cloudflare Workers deployments succeed and serve English and French routes under `/portfolio/` on GitHub Pages and `/` on Cloudflare.
8. Record notable changes in `CHANGELOG.md`.
