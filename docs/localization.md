# Localization

English and French are first-class website languages.

- English is the source language for repository documentation.
- Website content must remain aligned in meaning across both languages.
- On a first visit, use the client's browser preferences to select English or French.
- A visitor's explicit selection takes precedence and must be stored locally for subsequent visits.
- Use English as the fallback when the browser preference is unavailable or unsupported.
- A visible manual language switcher must always be available.
- Avoid literal translations when natural Canadian French communicates the intent more clearly.
