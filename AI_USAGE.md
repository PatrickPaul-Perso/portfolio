# Generative AI Usage

Generative AI is used in this repository as an engineering and writing assistant.

## Uses

AI may assist with:

- brainstorming and content structure
- software architecture exploration
- documentation drafting
- code generation and refactoring suggestions
- translation support
- accessibility review
- visual design exploration

## Human responsibility

Patrick Paul remains responsible for:

- technical and factual validation
- architecture decisions
- source code review
- security and accessibility review
- final editing
- publication approval

AI-generated output is not published without human review. The project favours small, reviewable changes over large generated rewrites.
